# Hello, Source Generator!

**Objective:** This exercise demonstrates how to create and integrate a source generation project into an existing solution, providing hands-on experience with .NET source generators. After completion you should be able to integrate a source generator into an existing project.

## 1. Create and Configure the Source Generator Project

### 1.1. Initial Setup and Verification

Begin by opening the provided solution and building the application to verify that all required SDKs are properly installed. Upon successful execution, the application should produce the following output:

```console
Hello?
```

### 1.2. Project Creation

Create a new project within the solution named `SourceGenerators`, utilizing either the empty project or class library template.

### 1.3. Project Configuration

Configure the project with the following specifications:

- Target the appropriate .NET framework version
- (Optional) Specify the desired language version
- Mark the project as a Roslyn component
- Enable extended analyzer rules enforcement
- Ensure the project assembly is excluded from build output

### 1.4. Build Verification and SDK Installation

Rebuild the solution. If prompted by your IDE to install the `.NET Compiler Platform SDK`, proceed with the installation. Should the build fail without an automatic SDK installation prompt, manually install the required components.

**For Visual Studio on Windows:**

1. Open Visual Studio Installer
2. Navigate to `Individual Components`
3. Install the `.NET Compiler Platform SDK`

### 1.5. Package Dependencies

Install the following NuGet packages:

- `Microsoft.CodeAnalysis.Analyzers`
- `Microsoft.CodeAnalysis.CSharp`

**Important:** Select package versions that are compatible with both the target language version and .NET framework version of your application. Refer to the [Roslyn GitHub documentation](https://github.com/dotnet/roslyn/blob/main/docs/wiki/NuGet-packages.md) for detailed versioning guidelines.

### 1.6. Project Reference Configuration

In the Application project, add a project reference to the SourceGenerators project with the following constraints:

- Reference the project as an analyzer
- Exclude the source generator from build output

Execute a final build to verify the configuration is correct and all components are functioning as expected.

## 2. Implement the Source Generator

### 2.1. Generator Implementation

Create a new file within the SourceGenerators project and implement it as an incremental source generator. Utilize a post-initialization output to generate the following code for the application:

```Csharp
// <auto-generated/>
namespace Application;

internal class MessageProvider : IMessageProvider
{
    public string GetWelcomeMessage() => "Hello, Source Generator!";
}
```

### 2.2. Verification and Testing

1. Build the solution and verify that the generated file has been successfully added to the application project
2. Execute the application to test the implementation

Upon successful completion of all steps, the application should greet you with output from your newly created source generator, demonstrating the successful integration of source generation into your development workflow.
